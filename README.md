## Versión en máxima calidad (320 MB, en una computadora con Windows)
Mirá el video **Como_armar_el_video_HD.mp4** o seguí estos pasos:

1. Botón verde **Code** → **Download ZIP**.
2. En *Descargas*, clic derecho sobre `Normita--main.zip` → **Extraer todo...** → **Extraer**.
3. Entrá a `Normita--main` → carpeta **MAXIMA_CALIDAD**.
4. Doble clic en **UNIR_VIDEO**. Si aparece *"Windows protegió su PC"*: **Más información** → **Ejecutar de todas formas**.
5. Aparece **Normita_MAXIMA_CALIDAD.mp4**: ese es el video completo.
